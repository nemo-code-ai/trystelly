# Stelly waitlist landing page

A responsive, static landing page for Stelly. The visual direction is warm, minimal and cinematic, with the supplied vertical Stelly ad used as the hero product film.

## Run locally
Open `index.html` in a browser, or run `npx serve .` from this folder.

## Included
- Responsive editorial-style landing page
- Compressed, muted, looping MP4 hero film with poster fallback
- Tally waitlist embed (`https://tally.so/r/zE70bq`)
- How-it-works section, FAQ and privacy page
- Subtle scroll reveal, disabled for reduced-motion preferences
- No build step or framework required

## Before publishing
1. Test the Tally embed and submit a test entry in your Tally workspace.
2. Add the final contact email and operating-entity details to `privacy.html` before collecting a large volume of signups.
3. Replace or add the real Stelly social profile URLs when they are ready.
4. Test the page on a phone and desktop. The video is muted and loops; users can still use their device's browser settings to control playback.

## Deploy to Vercel
Import this folder as a static project. No framework preset or build command is required; the project root is this folder.
